# weather-analysis-application
WAP is a small weather analysis application made in C#. The program lets users enter and manage weather data like temperature, humidity, and air pressure. Users can also view and analyze the stored information through a simple console menu system.

The application includes saving and loading features with CSV files, including an autosave system. This project was created as part of a school assignment and helped improve my understanding of C#, arrays, file handling, and general program structure.
